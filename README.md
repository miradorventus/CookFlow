# CookFlow

Recettes guidées pas à pas pour Thermomix TM6 et Ninja FlexDrawer DualZone. Marche hors ligne.

👉 **Ouvrir l'appli : [miradorventus.github.io/CookFlow](https://miradorventus.github.io/CookFlow/)**

## Installer l'appli
Il faut du réseau seulement la première fois. Ensuite, elle marche sans réseau.
- **iPhone** : ouvre le lien dans **Safari**, appuie sur Partager, puis « Sur l'écran d'accueil ».
- **Android** : ouvre le lien dans **Chrome**, menu ⋮, puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).

## Respect de tes données
Aucun compte. Recettes, planning, courses et réglages restent sur l'appareil. Une clé d'IA éventuelle n'est enregistrée que dans le téléphone.
